## About

I build production mobile applications and the web platforms behind them. My current
focus is **EBTEX**, a multi-tenant learning management platform serving schools and
private course centers — a React Native (Expo) client, a Laravel API, and a Next.js
public site, distributed as white-labeled apps on both stores.

---

## Current Focus

- **White-label distribution at scale** — build variants, per-tenant theming, and release
  automation for multiple institutions from a single codebase.
- **Backend depth** — extending beyond the frontend into Laravel service and API design.
